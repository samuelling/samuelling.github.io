# new-repos

Add an empty file here named for the repo you want (lowercase), push to
`main`, and the **New repo** workflow makes `samuelling/<name>` with GitHub
Pages on from `main`. It's live at `https://linglab.org/<name>/` within a
minute or two. A first line in the file becomes the repo's description.

The new repo starts with a README commit, so clone it and add to it rather
than pushing an unrelated history over it.
